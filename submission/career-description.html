오픈소스

OpenMMO — Contributor

2026.07–현재

AI 에이전트와 인간이 동일한 프로토콜로 플레이하는 오픈소스 MMORPG(Rust·Svelte·Three.js·WebAssembly). 게임 개발은 처음이었고, 클라이언트 테스트로 시작해 지금은 Rust 서버 쪽을 주로 본다. PR 10건 모두 병합. coding agent(Claude Code)와 페어로 진행하며 테스트·린트·타입·포맷을 통과한 변경만 제출.

  • 낚시 상태 전이·수면 높이 샘플링·클릭 인텐트 분기의 테스트 공백을 채우고, 세션이 끊길 때 뒤늦게 울리던 예약 사운드를 취소. 사거리 밖 물 클릭은 이동으로 바꾸고 사거리 값을 WebAssembly로 노출해 양쪽이 같은 값을 참조 (#56, #64, #65)
  • Rust 서버의 지형 타일 캐시가 쌓이기만 하고 줄지 않아, 읽기 경로는 락 없이 둔 채 세대 단위로 쓸어내고 용량 상한 적용 (#68). 운영자용 밴은 캐릭터가 아닌 계정으로 끊고, 검사를 지난 접속이 그대로 들어오는 틈을 세션 락으로 막음 (#95)
  • HUD 미니맵은 반대하던 메인테이너를 설계 제안서로 설득한 뒤 구현. 서버는 고치지 않고 기존 지형 타일을 쓰고, 위치를 계속 물어봐야 하는 파티원 마커는 리뷰를 받아 v1에서 뺌 (#11, #77)
  • 상인의 취침 스케줄은 에이전트 쪽 데이터라 서버가 못 보므로, 서버에 보이는 침대 점유로 수면을 판정해 잠든 상인과의 거래와 미리 열어둔 상점 창의 결제를 검증 한 곳에서 차단 (#103). 밤 거래 공백은 어두워지면 좌판을 여는 야간 상인으로 채우고, 두 파일에 나뉜 상인 정의가 한쪽만 등록된 경우를 잡는 테스트 작성 (#111)
  • 직접 겪은 온보딩 공백을 문서로 메움 — 지형 베이크 셋업 함정을 개발 문서에 (#78), CI 검사 명령과 착수 전 확인 사항을 CONTRIBUTING 가이드로 (#118)
