모호한 비즈니스 과제를 실제로 배포되는 AI 솔루션으로 바꿔온 7년차 엔지니어입니다. Levvels에서 운영팀에 임베드해 여러 내부 도구를 오가며 하나의 의사결정을 내리던 흐름을 문제로 정의하고, 자연어 요청을 실행 절차로 바꾸는 에이전트 자동화를 배포해 수 시간의 수작업을 수 분으로 줄인 뒤 현장에서 얻은 인사이트를 다시 제품에 반영했습니다. Claude Code 같은 AI 코딩 도구를 빌더/리뷰어 방식(빌더가 작성 → 별도 모델이 리뷰 → 테스트로 검증)으로 매일 활용하며, HCI·Visual Analytics 연구 배경 위에서 LLM 출력을 사람이 신뢰하고 실행할 수 있는 형태로 만드는 데 집중합니다. 고객과의 대화부터 동작하는 인터페이스까지 문제를 end-to-end로 책임지며, Python과 Unix 커맨드라인 환경에 익숙합니다.

핵심 역량

  • Agentic AI 배포 — 현장에서 제품으로: 운영팀과 함께 문제를 정의하고, 자연어 요청을 내부 도구 전반의 브라우저 액션으로 바꾸는 에이전트를 배포한 뒤, 현장 인사이트를 제품 개선으로 되먹임 (Levvels, PageAgent)
  • AI 코딩 도구 활용: Claude Code를 빌더/리뷰어 워크플로로 매일 사용 — 빌더가 작성, 별도 모델이 리뷰, 제출 전 테스트로 동작 고정. 라이브 코딩테스트에서 리뷰가 제출 직전 P0를 잡아냄
  • 비전문가를 위한 LLM 활용: 코드 없는 스튜디오 플로우와 설명가능 AI(XAI) 시각화를 만들어, ML 배경이 없는 엔터프라이즈 사용자가 AutoML 플랫폼을 운용하고 예측에 근거해 판단하게 함 (티맥스엔터프라이즈)
  • 스택 전반 오너십: 오픈소스 게임에 10개 PR 병합, TypeScript 클라이언트에서 Rust 서버까지 직접 수정. 필요하면 사용 가능한 인터페이스를 세우는 것도, 백엔드를 다루는 것도 가능
