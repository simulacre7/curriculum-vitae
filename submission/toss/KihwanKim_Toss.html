React·TypeScript로 7년간 제품을 만들어온 프론트엔드 엔지니어입니다. 유저가 보는 화면뿐 아니라 다른 개발자가 쓰는 SDK·툴체인, 상태가 복잡한 고밀도 어드민, 커진 코드베이스의 구조까지 다뤄왔습니다. 주어진 개발을 넘어 문제를 스스로 정의하고, 제약 안에서 무엇을 택하고 무엇을 포기했는지 설명하는 방식으로 일하며, TypeScript 클라이언트에서 Rust 서버·툴체인까지 필요한 곳이면 직접 고쳐 문제를 끝까지 해결합니다. Claude Code를 빌더/리뷰어 워크플로로 매일 씁니다.

핵심 역량

  • 다른 개발자가 쓰는 것 — SDK·툴체인·라이브러리: Vite·Vitest를 만든 VoidZero 툴체인에서 쉘 통합 버그를 Rust로 고치고 네 개 쉘 템플릿을 스냅샷 테스트로 고정(vite-plus #2508, 병합). 태스크 러너의 실행별 환경변수가 캐시를 매번 무효화하던 문제를 untrackedEnv 계약 확장으로 수정(vite-task #693). 사내 UI 라이브러리 정리·PageAgent 확장 경험
  • 고밀도 어드민 · 대규모 렌더링: windowing·동적 높이·스크롤 복원으로 대량 리스트 가상화(리디), 탐색·결제부터 취소·반품·교환·정산까지 상태 복잡한 커머스 어드민·스튜디오 구현(Vuddy)
  • 커진 코드베이스의 구조 세우기: 서버 주도 UI로 화면 변경을 배포 주기와 분리, PHP 페이지를 React로 점진 마이그레이션, 뒤섞인 사내 위젯 라이브러리 정리·React 대체
  • AI를 도구가 아니라 일하는 방식으로: Claude Code 빌더/리뷰어(빌더 작성→별도 모델 리뷰→테스트로 고정)를 매일 사용, LLM 스트리밍 응답을 상태 머신으로, 에이전트 출력의 신뢰성을 UI 구조(Generative UI)로 해결
  • End-to-end · 팀 경계 넘기: 오픈소스 MMORPG에 10개 PR 병합, TypeScript 클라이언트에서 Rust 서버까지 직접 수정하고 반대하던 메인테이너를 설계 제안서로 설득(OpenMMO)
